## jq

`jq` is a lightweight and flexible command-line JSON processor, similar to `awk`, `grep`, and `sed`.
It allows you to slice, filter, map, and transform structured JSON data with ease.

- [Documentation](https://jqlang.org/)
- [Source](https://github.com/jqlang/jq)
